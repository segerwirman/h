**Goal:** Evolve JARVIS from the completed local desktop-safe primitives into a secure remote-assisted, Google-connected, web-monitoring, creative-content copilot without opening generic desktop control, secret leakage, or unreviewed remote authority.

**Architecture:** Preserve the authority split: remote/voice/cron/delegation are untrusted request or read-only ingress; local desktop UI remains the confirmation authority; native bounded executors remain the only mutation path. Build new surfaces additively in editable modules; frozen files (`config/frozen_manifest.json`) remain untouched unless the user explicitly approves a frozen-boundary change.

**Tech stack:** Python 3.11, PyQt6, native agent registry/capability policy, encrypted secret store, Google OAuth, Playwright browser tools, SQLite/local artifact storage, cron scheduler, existing image provider integration.
